# Contributing

Contributions are welcome when they improve accuracy instead of simply making the list longer.

## Before adding a project

Please check that the project still exists, the relevant product is genuinely open source, and the link points to the official project or repository.

For a new entry, include:

- project name and official link;
- what proprietary product or use case it can replace;
- one short reason someone might choose it;
- important limitations when they materially affect the recommendation;
- useful labels such as **Self-hosted**, **Federated**, **Local-first**, or **Cross-platform** when accurate.

## Pull requests

Keep each pull request focused. Corrections, dead-link fixes, removals of abandoned software, and better alternatives are just as valuable as new entries.

Do not add affiliate links, referral codes, pirated software, malware, or projects whose source availability is only marketing without a meaningfully usable open-source product.
