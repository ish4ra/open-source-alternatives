# Curated open-source alternatives

A compact starting point for people replacing popular proprietary software and services.

## Social and publishing

- **Mastodon** — alternative to X/Twitter: https://joinmastodon.org/
- **Lemmy** — alternative to Reddit-style communities: https://join-lemmy.org/
- **Pixelfed** — alternative to Instagram-style photo sharing: https://pixelfed.org/
- **PeerTube** — alternative to centralized video platforms: https://joinpeertube.org/
- **Owncast** — alternative for self-hosted live streaming: https://owncast.online/

## Browsers and search

- **Firefox** — general-purpose open-source browser: https://www.mozilla.org/firefox/
- **LibreWolf** — Firefox-derived browser with privacy-focused defaults: https://librewolf.net/
- **Mullvad Browser** — privacy-focused browser based on Firefox ESR: https://mullvad.net/browser
- **SearXNG** — self-hosted metasearch engine: https://docs.searxng.org/

## Files and cloud

- **Nextcloud** — self-hosted files, calendar, contacts, and collaboration: https://nextcloud.com/
- **Seafile** — file synchronization and sharing: https://www.seafile.com/
- **Syncthing** — device-to-device file synchronization: https://syncthing.net/
- **LocalSend** — local-network file transfer: https://localsend.org/
- **Kopia** — backup tool with snapshots and encryption: https://kopia.io/
- **Restic** — command-line backup program: https://restic.net/

## Photos and media

- **Immich** — self-hosted photo and video library: https://immich.app/
- **PhotoPrism** — self-hosted photo management: https://www.photoprism.app/
- **Jellyfin** — self-hosted media server: https://jellyfin.org/
- **Kodi** — open-source media center: https://kodi.tv/
- **VLC** — cross-platform media player: https://www.videolan.org/vlc/
- **mpv** — lightweight media player: https://mpv.io/

## Music

- **Navidrome** — self-hosted music server: https://www.navidrome.org/
- **Funkwhale** — self-hosted and federated audio platform: https://www.funkwhale.audio/
- **Strawberry** — desktop music player and organizer: https://www.strawberrymusicplayer.org/

## Notes and productivity

- **Joplin** — notes and to-do application with synchronization options: https://joplinapp.org/
- **Logseq** — local-first knowledge management and outlining: https://logseq.com/
- **Notesnook** — open-source notes application: https://notesnook.com/
- **LibreOffice** — desktop office suite: https://www.libreoffice.org/
- **ONLYOFFICE Community** — office and document collaboration tools: https://www.onlyoffice.com/
- **Vikunja** — self-hosted tasks and project planning: https://vikunja.io/
- **OpenProject** — project management platform: https://www.openproject.org/

## Creative tools

- **GIMP** — raster image editor: https://www.gimp.org/
- **Krita** — digital painting and illustration: https://krita.org/
- **Inkscape** — vector graphics editor: https://inkscape.org/
- **Penpot** — collaborative interface design: https://penpot.app/
- **Kdenlive** — non-linear video editor: https://kdenlive.org/
- **Shotcut** — cross-platform video editor: https://shotcut.org/
- **Audacity** — audio recording and editing: https://www.audacityteam.org/
- **OBS Studio** — screen recording and live production: https://obsproject.com/

## Developer tools

- **Forgejo** — self-hosted Git forge: https://forgejo.org/
- **Gitea** — lightweight self-hosted Git forge: https://about.gitea.com/
- **VSCodium** — community build of VS Code without Microsoft branding/telemetry defaults: https://vscodium.com/
- **Neovim** — extensible terminal editor: https://neovim.io/
- **Bruno** — API client with files stored in your repository: https://www.usebruno.com/
- **Hoppscotch** — web-based API development tool: https://hoppscotch.io/

## Self-hosted infrastructure

- **Home Assistant** — home automation platform: https://www.home-assistant.io/
- **openHAB** — vendor-neutral home automation: https://www.openhab.org/
- **Pi-hole** — network-level DNS filtering: https://pi-hole.net/
- **AdGuard Home** — network-wide DNS filtering: https://adguard.com/adguard-home/overview.html
- **RustDesk** — remote desktop software: https://rustdesk.com/
- **MeshCentral** — remote device management: https://meshcentral.com/

## Local AI

- **Ollama** — run supported language models locally: https://ollama.com/
- **llama.cpp** — local inference for compatible language models: https://github.com/ggml-org/llama.cpp
- **LocalAI** — self-hosted local AI API stack: https://localai.io/
- **Open WebUI** — web interface for local and self-hosted AI backends: https://openwebui.com/
