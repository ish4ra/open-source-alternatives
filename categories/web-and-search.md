# Web browsers and search

## Browsers

- **[Firefox](https://www.mozilla.org/firefox/)** — mature cross-platform open-source browser.
- **[LibreWolf](https://librewolf.net/)** — Firefox-derived browser with more privacy-oriented defaults.
- **[Mullvad Browser](https://mullvad.net/browser)** — Firefox ESR-based browser designed to reduce tracking and fingerprinting.
- **[Helium](https://helium.computer/)** — privacy-first Chromium browser based on ungoogled-chromium, with a deliberately minimal interface and open-source browser components/tooling. **Beta/young project:** attractive for enthusiasts, but evaluate maturity and update/security trust for sensitive use.
- **[Cromite](https://github.com/uazo/cromite)** — Chromium-based browser for Android with privacy and ad-blocking features.

## Search

- **[SearXNG](https://docs.searxng.org/)** — self-hosted metasearch engine that aggregates results from multiple providers.
- **[Whoogle Search](https://github.com/benbusby/whoogle-search)** — self-hosted frontend for Google Search results.
- **[LibreY](https://github.com/Ahwxorg/LibreY)** — privacy-oriented metasearch frontend.

For most people, Firefox or LibreWolf plus a trustworthy SearXNG instance is the conservative open-source starting point. Helium is an interesting Chromium-side hidden gem if you specifically want a leaner, privacy-oriented Chromium experience and are comfortable using a younger beta project.
