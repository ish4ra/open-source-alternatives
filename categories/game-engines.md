# Game engines

- **[Godot](https://godotengine.org/)** — full 2D/3D game engine with its own editor and scripting language.
- **[Bevy](https://bevyengine.org/)** — data-driven Rust game engine focused on ECS architecture.
- **[GDevelop](https://gdevelop.io/)** — visual game engine aimed at fast 2D development and non-programmers.

Godot is the strongest general-purpose open-source alternative to Unity-style workflows.
