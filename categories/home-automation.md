# Home automation

- **[Home Assistant](https://www.home-assistant.io/)** — local-first home automation platform with a large integration ecosystem.
- **[openHAB](https://www.openhab.org/)** — vendor-neutral home automation platform with extensive device support.
- **[ESPHome](https://esphome.io/)** — firmware and tooling for building ESP-based smart-home devices.
- **[Node-RED](https://nodered.org/)** — visual automation flows useful for connecting devices and services.

Home Assistant is the strongest general-purpose starting point for a self-managed smart home.
