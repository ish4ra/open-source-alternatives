# File managers

- **[Dolphin](https://apps.kde.org/dolphin/)** — KDE file manager with tabs, split views, network locations, and powerful previews.
- **[Thunar](https://docs.xfce.org/xfce/thunar/start)** — lightweight file manager from Xfce.
- **[PCManFM-Qt](https://github.com/lxqt/pcmanfm-qt)** — lightweight Qt file manager used by LXQt.
- **[Double Commander](https://doublecmd.sourceforge.io/)** — dual-pane file manager inspired by Total Commander.

Dolphin is feature-rich, Thunar/PCManFM-Qt are lighter, and Double Commander suits keyboard-heavy dual-pane workflows.
