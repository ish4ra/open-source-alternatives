# PDF tools

- **[Stirling PDF](https://www.stirlingpdf.com/)** — self-hostable toolbox for merging, splitting, converting, and processing PDFs.
- **[PDF Arranger](https://github.com/pdfarranger/pdfarranger)** — desktop tool for reordering, merging, splitting, and rotating PDF pages.
- **[Okular](https://okular.kde.org/)** — document viewer with annotation support.

- **[Glim](https://github.com/NeoPanic/Glim)** — **Local-first**, MIT-licensed macOS file viewer for basic PDF reading alongside Markdown and data files. Covers the viewing part of Adobe Acrobat workflows; PDF previews are read-only, without annotation or page-editing tools. Current DMGs are not Apple-notarized; follow the [first-launch instructions](https://github.com/NeoPanic/Glim#download).

Use Stirling PDF for a broad browser-based toolbox and PDF Arranger for quick local page operations.
