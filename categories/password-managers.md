# Password managers

Open-source alternatives to proprietary password managers such as 1Password and Dashlane.

- **[Bitwarden](https://bitwarden.com/)** — cross-platform password manager with open-source clients and optional self-hosting.
- **[KeePassXC](https://keepassxc.org/)** — local-first desktop password manager using the KeePass database format.
- **[KeePassDX](https://www.keepassdx.com/)** — Android KeePass client focused on offline use and local control.
- **[Vaultwarden](https://github.com/dani-garcia/vaultwarden)** — lightweight community server compatible with Bitwarden clients.

For most people, Bitwarden is the easiest hosted option; KeePassXC is ideal when you want a fully local vault.
