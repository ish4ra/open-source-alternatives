# Desktop publishing

- **[Scribus](https://www.scribus.net/)** — page layout and desktop publishing for brochures, books, posters, and print-ready PDFs.
- **[LaTeX](https://www.latex-project.org/)** — document preparation system especially strong for technical and academic publishing.
- **[LyX](https://www.lyx.org/)** — graphical document processor built around LaTeX.

Scribus is the closest open-source alternative to InDesign-style page layout; LaTeX is stronger for structured technical documents.
