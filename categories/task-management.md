# Task management

- **[Vikunja](https://vikunja.io/)** — tasks, lists, kanban boards, and collaboration with self-hosting support.
- **[Tasks.org](https://tasks.org/)** — Android task manager with CalDAV and other sync options.
- **[Super Productivity](https://super-productivity.com/)** — desktop/web task manager with time tracking and integrations.

Vikunja is the strongest self-hosted team/personal option; Tasks.org is excellent for Android-first workflows.
