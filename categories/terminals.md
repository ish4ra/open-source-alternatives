# Terminal emulators

- **[Alacritty](https://alacritty.org/)** — fast cross-platform terminal emulator.
- **[kitty](https://sw.kovidgoyal.net/kitty/)** — GPU-accelerated terminal with tabs, layouts, and advanced features.
- **[WezTerm](https://wezterm.org/)** — cross-platform terminal with Lua configuration and multiplexing features.
- **[Foot](https://codeberg.org/dnkl/foot)** — lightweight Wayland-native terminal for Linux.

Alacritty favors simplicity and speed; kitty and WezTerm include more built-in power-user features.
