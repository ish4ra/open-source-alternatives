# E-commerce

- **[Medusa](https://medusajs.com/)** — modular commerce backend for custom storefronts.
- **[Saleor](https://saleor.io/)** — GraphQL-first commerce platform for larger custom deployments.
- **[WooCommerce](https://woocommerce.com/)** — open-source commerce plugin for WordPress.
- **[PrestaShop](https://www.prestashop-project.org/)** — standalone open-source online store platform.

WooCommerce is easiest for WordPress sites; Medusa and Saleor suit more custom application stacks.
