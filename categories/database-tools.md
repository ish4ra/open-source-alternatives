# Database tools

- **[DBeaver Community](https://dbeaver.io/)** — cross-platform database client supporting many SQL databases.
- **[Beekeeper Studio Community](https://www.beekeeperstudio.io/)** — friendly SQL editor and database manager.
- **[pgAdmin](https://www.pgadmin.org/)** — administration and development tool focused on PostgreSQL.
- **[SQLite Browser](https://sqlitebrowser.org/)** — visual editor for SQLite database files.

DBeaver is the broadest general database client; pgAdmin and SQLite Browser are better when you only need their specific database families.
