# Diagramming

- **[diagrams.net](https://www.diagrams.net/)** — general-purpose flowcharts, network diagrams, UML, and technical diagrams.
- **[Excalidraw](https://excalidraw.com/)** — collaborative hand-drawn-style diagrams and whiteboards.
- **[Mermaid](https://mermaid.js.org/)** — text-based diagrams that work well in documentation and repositories.
- **[PlantUML](https://plantuml.com/)** — text-based UML and software architecture diagrams.

Excalidraw is great for quick visual thinking; Mermaid and PlantUML are ideal when diagrams should live as text alongside documentation.
