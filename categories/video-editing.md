# Video editing

- **[Kdenlive](https://kdenlive.org/)** — full-featured non-linear editor built on KDE/MLT.
- **[Shotcut](https://shotcut.org/)** — cross-platform non-linear editor with broad format support.
- **[Olive](https://www.olivevideoeditor.org/)** — open-source non-linear editor under active development.

Kdenlive is the strongest general-purpose pick; Shotcut is approachable and cross-platform.
