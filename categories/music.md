# Music

- **[Navidrome](https://www.navidrome.org/)** — lightweight self-hosted music server compatible with Subsonic clients.
- **[Funkwhale](https://www.funkwhale.audio/)** — self-hosted and federated audio platform.
- **[Ampache](https://ampache.org/)** — long-running web music server and streaming application.
- **[Strawberry](https://www.strawberrymusicplayer.org/)** — desktop music player and collection manager.

Navidrome is a strong choice for a personal streaming server; Strawberry is aimed at local desktop libraries.
