# Vector and interface design

- **[Inkscape](https://inkscape.org/)** — vector graphics editor for illustration, diagrams, icons, and print work.
- **[Penpot](https://penpot.app/)** — collaborative interface design and prototyping with a self-hostable edition.
- **[SVG-Edit](https://github.com/SVG-Edit/svgedit)** — browser-based SVG editor.

Use Inkscape for Illustrator-style vector work and Penpot for Figma-style collaborative UI design.
