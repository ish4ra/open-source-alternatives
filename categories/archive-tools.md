# Archive tools

- **[7-Zip](https://www.7-zip.org/)** — widely used archive utility with strong compression support.
- **[PeaZip](https://peazip.github.io/)** — cross-platform archive manager with a broad format set.
- **[Ark](https://apps.kde.org/ark/)** — KDE archive manager integrated with Linux desktops.
- **[File Roller](https://gitlab.gnome.org/GNOME/file-roller)** — GNOME archive manager.

7-Zip is the standard Windows recommendation; PeaZip is useful when you want a cross-platform GUI.
