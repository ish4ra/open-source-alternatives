# Code hosting

- **[Forgejo](https://forgejo.org/)** — community-driven self-hosted Git forge with issues, pull requests, packages, and actions support.
- **[Gitea](https://about.gitea.com/)** — lightweight self-hosted Git service.
- **[GitLab Community Edition](https://about.gitlab.com/install/)** — larger DevOps platform with source hosting, CI/CD, and project management.
- **[SourceHut](https://sr.ht/)** — open-source software development platform built around simple Unix-style tools.

Forgejo and Gitea are the easiest GitHub-style self-hosted starting points.
