# Calendars

- **[Etar](https://github.com/Etar-Group/Etar-Calendar)** — open-source Android calendar app.
- **[Fossify Calendar](https://github.com/FossifyOrg/Calendar)** — simple Android calendar with local-first usage.
- **[Radicale](https://radicale.org/)** — lightweight CalDAV/CardDAV server for self-hosted calendars and contacts.
- **[Thunderbird](https://www.thunderbird.net/)** — desktop mail client with integrated calendar support.

Use Radicale when you need a self-hosted sync backend and Etar/Fossify for straightforward Android calendar clients.
