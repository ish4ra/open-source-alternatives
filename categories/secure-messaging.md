# Secure messaging

Open-source messaging apps differ most in their **network model**. A secure app can be centralized, federated, peer-to-peer, or self-hostable — those are separate choices from whether the code is open.

## Signal

- **[Signal](https://signal.org/)** — polished end-to-end encrypted messaging, voice/video calls and groups.
- The Android client and server code are published openly.
- The service itself is **centralized**: you use Signal's service rather than choosing a federated homeserver.

**Best for:** people who want a straightforward private messenger with strong defaults and broad usability.

## Element + Matrix

- **[Matrix](https://matrix.org/)** — open federated communication protocol and network.
- **[Element](https://element.io/)** — prominent open-source client for Matrix, including Android.
- You can use a hosted Matrix provider or run your own homeserver.

**Best for:** people who value federation, server choice, communities/rooms, interoperability, or self-hosting.

> **Matrix is the protocol/network; Element is a client.** They are related but not interchangeable names.

## Which should you choose?

| Need | Better starting point |
|---|---|
| Simple private chats/calls | **Signal** |
| Federation / server choice | **Matrix + Element** |
| Self-hosted messaging infrastructure | **Matrix ecosystem** |
| Lowest setup friction | **Signal** |
| Large rooms / community-style spaces | **Matrix + Element** |

Both are valid open-source alternatives; the right choice depends more on the network model you want than on a generic "privacy" score.
