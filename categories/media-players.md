# Media players

- **[VLC](https://www.videolan.org/vlc/)** — cross-platform player with broad codec and streaming support.
- **[mpv](https://mpv.io/)** — lightweight, scriptable media player popular with power users.
- **[Celluloid](https://celluloid-player.github.io/)** — GTK frontend for mpv with a simpler desktop interface.
- **[Haruna](https://haruna.kde.org/)** — KDE media player built on mpv.
- **[Stremio](https://www.stremio.com/)** — open-source media-center/streaming hub with an addon-based catalog and playback model; its official desktop shell and web client are published as open-source projects. Available content depends on the addons/services a user chooses.
- **[Ampcast](https://github.com/rekkyrosso/ampcast)** — Winamp-inspired open-source music player that can connect to Jellyfin, Navidrome/Subsonic, Plex, Emby and other sources; available as a web/PWA, desktop app and self-hosted instance.

Choose VLC for an all-purpose GUI, mpv for scripting and minimalism, Celluloid/Haruna when you want mpv with a friendlier interface, Stremio for an addon-driven media discovery/streaming interface, and Ampcast when you want one music-focused frontend across several libraries/services.
