# Documentation sites

- **[MkDocs](https://www.mkdocs.org/)** — Markdown documentation generator with a large plugin/theme ecosystem.
- **[Docusaurus](https://docusaurus.io/)** — React-based documentation and content framework.
- **[VitePress](https://vitepress.dev/)** — fast Vue-powered static site generator for documentation.
- **[Sphinx](https://www.sphinx-doc.org/)** — mature documentation generator widely used in Python and technical projects.

MkDocs is the easiest general-purpose starting point; Sphinx is especially strong for API-heavy technical documentation.
