# Translation

Open-source alternatives to proprietary translation services and apps.

- **[LibreTranslate](https://libretranslate.com/)** — open-source machine-translation API and web interface that can be self-hosted.
- **[Apertium](https://www.apertium.org/)** — rule-based machine-translation platform focused on related and lower-resource languages.
- **[Argos Translate](https://www.argosopentech.com/)** — offline neural machine translation for desktop and Python workflows.
- **[Crow Translate](https://crow-translate.github.io/)** — lightweight desktop translation interface supporting multiple backends and text-to-speech.

LibreTranslate is the simplest self-hosted web option; Argos Translate is useful when offline translation matters.
