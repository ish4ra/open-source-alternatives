# Files, sync, and backups

- **[Nextcloud](https://nextcloud.com/)** — self-hosted file storage plus calendar, contacts, and collaboration.
- **[Seafile](https://www.seafile.com/)** — efficient file synchronization and sharing.
- **[Syncthing](https://syncthing.net/)** — peer-to-peer file synchronization between your own devices.
- **[LocalSend](https://localsend.org/)** — local-network file transfer between phones and computers.
- **[Kopia](https://kopia.io/)** — snapshot-based backup software with encryption and multiple storage targets.
- **[Restic](https://restic.net/)** — fast command-line backup tool with encrypted repositories.
- **[BorgBackup](https://www.borgbackup.org/)** — deduplicating backup program popular on Unix-like systems.

Nextcloud and Seafile replace cloud-drive workflows; Syncthing is better for direct device-to-device sync; Kopia, Restic, and Borg are backup tools rather than cloud drives.
