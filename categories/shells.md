# Command shells

- **[fish](https://fishshell.com/)** — friendly interactive shell with autosuggestions and sensible defaults.
- **[Nushell](https://www.nushell.sh/)** — shell that treats pipeline data as structured values instead of plain text.
- **[Zsh](https://www.zsh.org/)** — mature Unix shell with extensive completion and customization.
- **[Elvish](https://elv.sh/)** — expressive shell with structured data features.

fish is the easiest usability upgrade; Nushell is the most different if you want structured pipelines.
