# Remote desktop

- **[RustDesk](https://rustdesk.com/)** — cross-platform remote desktop with self-hosting support.
- **[MeshCentral](https://meshcentral.com/)** — web-based remote device management for fleets of computers.
- **[Remmina](https://remmina.org/)** — Linux remote desktop client supporting RDP, VNC, SSH, and more.
- **[Apache Guacamole](https://guacamole.apache.org/)** — browser-based remote desktop gateway.

RustDesk is the closest general alternative to TeamViewer/AnyDesk-style usage; Guacamole is useful when access should happen through a browser.
