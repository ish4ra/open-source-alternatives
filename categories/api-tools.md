# API development tools

- **[Bruno](https://www.usebruno.com/)** — API client that stores collections as plain files in your project.
- **[Hoppscotch](https://hoppscotch.io/)** — browser-based API development tool with REST, GraphQL, WebSocket, and other workflows.
- **[HTTPie](https://httpie.io/)** — command-line HTTP client with a human-friendly syntax.
- **[Yaak](https://yaak.app/)** — open-source desktop API client focused on a clean local workflow.

Bruno is especially useful when API collections should be version-controlled alongside code.
