# Local AI tools

- **[Ollama](https://ollama.com/)** — simple local model runner for supported language and multimodal models.
- **[llama.cpp](https://github.com/ggml-org/llama.cpp)** — efficient local inference engine with broad hardware support.
- **[LocalAI](https://localai.io/)** — self-hosted OpenAI-compatible API layer for local models.
- **[Open WebUI](https://openwebui.com/)** — browser interface for local and self-hosted AI backends.

Ollama + Open WebUI is an approachable desktop/server combination; llama.cpp offers lower-level control.
