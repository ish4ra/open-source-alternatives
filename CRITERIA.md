# Selection criteria

This directory aims to recommend **credible open-source alternatives**, not every project that happens to publish source code.

A project is a strong candidate when it meets most of these points:

- the relevant product is open source under a recognizable license;
- the project is maintained or still has a healthy user/developer community;
- it can realistically replace part or all of a popular proprietary product;
- setup and limitations can be explained honestly;
- the project has a stable homepage or source repository;
- there is no obvious reason to consider it abandoned or unsafe.

## Things we do not assume

Open source does **not** automatically mean private, secure, free-of-cost, decentralized, or self-hosted. Those are separate properties and should be described separately.

## Removal reasons

Entries may be removed when a project is abandoned, changes to a non-open license, becomes misleading to recommend, repeatedly ships serious unresolved security problems, or is superseded by a clearly better maintained successor.
